# Sri U-Thong Hotel Website

This folder holds the Astro marketing site for Sri U-Thong Grand Hotel.

It is kept separate from the Next.js Hotel Inventory Bridge so both apps can be developed and deployed cleanly.

Main site areas:

- home
- rooms
- dining
- gallery
- location
- meetings and events
- contact

The source app is in `src/`, static assets are in `public/`, and the generated site output goes to `dist/`.
